# AGENTS.md

Project guidelines for coding agents. The substantive behavioral guidelines
live in [CLAUDE.md](CLAUDE.md) — read it first; everything there applies to any
agent working in this repo, not just Claude.

## Documented Solutions

`docs/solutions/` — documented solutions to past problems (bugs, best practices,
architecture/design patterns), organized by category with YAML frontmatter
(`module`, `tags`, `problem_type`). Relevant when implementing or debugging in
documented areas — search it before starting work in an area it may cover.
